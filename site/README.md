# CENOFEX — сайт и админ-панель

Сайт на чистом PHP + MySQL. Контент редактируется через админ-панель.
Страницы отдаются как статика (кэш), поэтому загружаются быстро.

## Что где

```
app/          ядро (конфиг, БД, авторизация) — закрыто от посетителей
admin/        админ-панель
assets/       site.css, site.js — общие стили и скрипты сайта
az/           азербайджанская версия (/az/)
storage/cache статические копии страниц (создаются автоматически)
uploads/      загруженные логотипы партнёров и фото
render.php    шаблон страницы (собирает HTML из базы)
index5.php    английская версия (главная рабочая страница)
install.php   установщик — УДАЛИТЬ после установки
```

## Установка (один раз)

1. **Создать базу данных.** cPanel → *MySQL Databases*:
   - создать БД, например `cenofex_site`
   - создать пользователя и дать ему **All Privileges** на эту БД

2. **Прописать доступы.** cPanel → *File Manager* → `public_html/app/config.php`
   (файл создаётся при первом деплое) — заполнить `name`, `user`, `pass`.

3. **Запустить установщик:** открыть `https://cenofex.ai/install.php`
   - создаст таблицы
   - перенесёт все текущие тексты сайта (EN + AZ)
   - добавит логотипы партнёров из `/images/partners`
   - создаст первого администратора

4. **Удалить `install.php`** с сервера.

5. Войти: `https://cenofex.ai/admin/login.php`

## Возможности панели

- **Тексты сайта** — все надписи на двух языках, EN и AZ рядом
- **Услуги и решения** — карточки: добавить, изменить, скрыть, отсортировать
- **Партнёры** — загрузка логотипов, порядок, ссылки
- **Изображения** — фото слайдов и блока «О компании» (файл или ссылка)
- **SEO** — title, description, картинка для соцсетей, почта для заявок, соцсети
- **Пользователи** — добавление, роли (администратор / редактор), смена паролей
- **Вход** с восстановлением пароля по e-mail

## Скорость

При первом заходе страница собирается из базы и сохраняется в
`storage/cache/page_en.html`. Дальше посетители получают готовый HTML —
база не опрашивается. Кэш сбрасывается автоматически при любом
сохранении в панели (или кнопкой «Обновить кэш» на главной панели).

## Безопасность

- пароли хранятся в виде хэша (`password_hash`)
- защита форм от CSRF
- в `uploads/` запрещено выполнение PHP
- папки `app/` и `storage/` закрыты от прямого доступа
- ссылка сброса пароля живёт 60 минут и действует один раз
- в форме обратной связи — скрытая ловушка для ботов

## Обновление сайта

```bash
git add -A && git commit -m "..." && git push
```
Затем в cPanel → *Git Version Control* → **Update from Remote** → **Deploy HEAD Commit**.

`app/config.php` при деплое не перезаписывается — пароль от БД сохраняется.
